# Yuang Wei — Academic Homepage

This repository hosts the English academic homepage of Yuang Wei, Lecturer at the Faculty of Artificial Intelligence in Education, Central China Normal University.

Live site: <https://philrainv.github.io/YuangWei_EN/>

The site is a responsive static application with publication filtering, highlighted authorship, Google Scholar metrics, linked education and research profiles, and an anonymized visitor-distribution map. Citation data are refreshed by the workflow in `.github/workflows/google_scholar_crawler.yaml`.

The Chinese homepage is available at <https://philrainv.github.io/>.
